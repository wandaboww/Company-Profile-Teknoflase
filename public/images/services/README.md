# Folder Gambar Layanan & Portofolio TEKNOFLASE

Simpan berkas gambar layanan dan portofolio Anda di dalam folder ini (misal: `pilates-1.jpg`, `toko-online.webp`, dll.).

### Cara Memanggil Gambar di Admin Panel:
Pada kolom **"Atau tempel URL gambar"** di Admin Panel, cukup masukkan path URL lokal:
`/images/services/nama-file-gambar.jpg`

Contoh:
`/images/services/pilates-1.jpg`

### Keunggulan:
1. Otomatis ikut ter-upload ke server saat menjalankan `git push`.
2. Tidak memakan kuota `localStorage` browser.
3. Bebas dari masalah CORS, hotlink protection, atau link rusak.
4. Loading gambar sangat cepat dan permanen.
